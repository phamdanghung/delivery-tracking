## Database

Migration chuẩn bị: `0001`. **Chưa chạy migration lên database thực tế.** Alembic nhận đúng một head và xuất SQL offline thành công; đây không phải bằng chứng migration đã thực thi.

Baseline gồm 17 bảng nghiệp vụ: users, vehicles, driver_profiles, deliveries, trips, trip_stops, delivery_status_events, pod_photos, tracking_tokens, fuel_profiles, fuel_entries, expenses, maintenance_rules, maintenance_events, vehicle_documents, safety_alerts, audit_logs. Có bốn enum, extension PostGIS/pgcrypto và index theo SQL gốc. Khi chạy Alembic, thêm bảng quản lý phiên bản `alembic_version`.

Không sửa trường hoặc ràng buộc nghiệp vụ đã cung cấp.

## Hướng dẫn kiểm tra lại

Khi Docker Linux Engine hoạt động, từ thư mục gốc:

```powershell
./scripts/dev.ps1
docker compose ps
Invoke-RestMethod http://localhost:8000/health/live
Invoke-RestMethod http://localhost:8000/health/ready
./scripts/verify.ps1
```

Readiness phải trả HTTP 200 với cả bốn check true. Migration và integration test chạy trên **database test riêng** theo README/CI; không thử downgrade trên dữ liệu vận hành.

Để đóng M0 còn cần: sửa môi trường Docker, chạy stack/image/migration và test database thật, xử lý dependency advisory, kết nối remote/chạy CI và báo cáo lại các điều kiện thoát. Không cần quyết định nghiệp vụ mới để tiếp tục kiểm tra nền tảng này.
